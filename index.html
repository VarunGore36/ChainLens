Capabilities

Key Features

Production-grade Ethereum indexer built in Rust.

⟠

ERC-20 & ERC-721

Transfer events decoded into typed tables. Token transfers indexed separately for fast queries by address or contract.

🔄

Reorg Handling

Detects chain reorganizations, identifies common ancestor, rolls back orphaned range atomically.

📡

Prometheus Metrics

Blocks/sec, tx/sec, RPC latency, DB commit time, indexing lag, reorg count — all at /metrics.

🌐

Query API

Axum REST API with keyset pagination. Block, transaction, address history, contract events.

🛡️

Security

Read-only API, localhost binding, RedactedUrl prevents credential leaks, no private keys.

🐳

Docker Ready

PostgreSQL + Prometheus + Grafana in docker-compose. Tuned for benchmarking with data checksums.

Setup

Quick Start

Get running in 3 commands.

# Clone and configure git clone https://github.com/VarunGore36/ChainLens.git cd ChainLens cp .env.example .env # add your RPC endpoint # Start PostgreSQL docker compose up -d # Run the indexer cargo run --bin chainlens # Run the API (separate terminal) cargo run --bin api # API at http://127.0.0.1:8080
